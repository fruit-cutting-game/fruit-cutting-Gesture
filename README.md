🎯 About the Project
Fruit Cutting Gesture Game is an interactive game controlled by hand gestures using a webcam.
Players move their hands in front of the camera to control the virtual blade. The application uses computer vision and hand-tracking technology to detect movements and interact with fruits.
✨ Features
Webcam Control: Control the game using a webcam.
Hand Tracking: Track hand movements using MediaPipe.
Fruit Cutting: Cut fruits using gesture-based movements.
Collision Detection: Detect interactions between the blade and fruits.
Visual Effects: Display blade trails and game effects.
Score System: Track the player's score.
Sound Effects: Provide audio feedback during gameplay.
